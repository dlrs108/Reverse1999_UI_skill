# Layout Patterns

## 1. The "Archive" Layout (Tasks & Stats)
- **Background**: Dark charcoal with a massive, transparent Serif watermark (e.g., "DOCUMENT").
- **Top Nav**: Left-aligned. Thin 1px lines. Active tab has orange background.
- **Main Content**: A vertical stack of horizontal paper cards. 
- **Staggering**: Apply slight `margin-left: 2%` and `margin-right: -2%` to alternating cards, creating a physical, stacked effect.

## 2. Magazine Profile Layout (Character Info)
- **Left column**: Massive vertical text, a custom script signature floating below the character art.
- **Right column**: Paper panels overlapping the dark background. 
- **Typography**: Use a huge orange Drop Cap for the first letter of the text block. Text is justified with tight line-height.
- **Geometric Accents**: Intersecting triangles (for insight nodes) with 1px glowing borders.

## 3. The "Combat/Preparation" Layout
- **Character Cards**: Vertical rectangles. Left edge has an elemental icon. Bottom has a health bar (chamfered green parallelogram) and moxie slots (diamonds).
- **Buttons**: `开始行动` button must have an orange background, a chamfered right edge, and a tiny downward triangle `▼` in the top right corner.
